# EndoSRR Failure Analysis

Master Thesis Research Project

## Research Objective
Analysis of specular reflection removal in endoscopic images.
Investigation of failure patterns by reflection size and shape.
Future research: multi-scale improvement of EndoSRR.

## Baseline Model
Original repository: https://github.com/Tobyzai/EndoSRR
Baseline inference tested on Apple Silicon using PyTorch MPS.

## Current Progress
- Baseline inference completed on two images
- Reflection masks and restored images generated
- Pixel difference visualization implemented
- Failure analysis planned

## Project Structure
- src/baseline: Modified baseline code and patches
- src/analysis: Image analysis scripts
- experiments: Experimental records
- docs: Research notes

## Data Management
Medical images and pretrained weights are excluded.
